彙整全隊減傷軸的流程

  1. 每個隊員
    職責選自己 → 按 編輯減傷，在要按的招式下面 ＋ 減傷 加上自己的技能。
  2. 每個隊員
    按 匯出分享碼 → 複製，把一串分享碼貼到群組給整理的人。
  3. 整理的人
    按 匯入分享碼 → 貼上 → 下一步。
  4. 整理的人
    只勾這個人負責的職責（例如 H1 傳來的就只勾 H1）→ 匯入勾選的。沒勾的會保留原本內容，不會被蓋掉。
    H1 占星改了 5 招
    H2 學者沒有改動
  5. 整理的人
    每個人的碼都照第 3、4 步匯入一次，全部合併好後再 匯出分享碼，貼回群組。
  6. 全隊
    匯入整理好的碼，全部勾選 → 大家的軸就一致了。

自訂內容只存在自己的瀏覽器。換電腦或清除瀏覽資料前，記得先匯出備份。

每一行是 Boss 技能的判定時間，圈數字是這招第幾次出現。門神狼頭之後的時間會隨打速前後差幾秒。

空白筆記：只有 Boss 技能時間軸和機制標籤，減傷、站位都是空的。按「編輯減傷」填上你們隊伍的減傷，每一行也可以寫自己的筆記；填好後可以匯出分享碼給隊友匯入。設定只存在你自己的瀏覽器。

五個平台圍成一圈，相鄰平台用傳送裝置移動。C 平台是最下面（初始南邊）那個，開場全員在 C。P3 鎧袖一觸 ② Boss 轉面向後，C 改成 Boss 正面的平台。

組別平台：MT 組（MT、H1、D1、D3）在 C左，ST 組（ST、H2、D2、D4）在 C右。

「往上一格」是沿著圈往離 C 更遠的方向走：C左 → 左上、C右 → 右上。

一運平台編號（藍色數字）：C左 是 1，順時針依序 左上 2、右上 3、C右 4。

編輯減傷中　每一招下面按「＋ 減傷」新增，按技能旁的 × 刪除；「＋ 站位」或站位後面的 ✎ 可以改站位；「＋ 標籤／✎ 標籤」可以改機制標籤。改動只存在你自己的瀏覽器。

時間照 cactbot 的 M8S 時間軸換算。預設的 # 機制標籤沿用版主筆記（MMW、蘇帕的打法），打法不同可以在編輯模式自己改。「看圖」的站位圖取自猫猫窝攻略组的機制速覽。
