## 使用說明

- 時間軸小抄可以切換職位，看各自的減傷、站位和要注意的機制。
- 版主筆記的減傷軸是照作者隊伍的組成排的，拿去用的話記得依你們的隊伍重新調整。
- 按「編輯減傷」就能改每個人放的技能，也能寫自己的筆記、貼上圖片。
- 改好的內容可以匯出成**分享碼**（減傷軸＋文字筆記）或**下載成檔案**（連圖片一起），給隊友匯入。
- 設定和筆記只存在你自己的瀏覽器裡，不會上傳。
