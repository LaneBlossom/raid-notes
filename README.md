## 使用說明

- 時間軸小抄可以切換職位，看各自的減傷、站位和要注意的機制。
- 減傷軸是照作者自己隊伍的組成和打法排的，拿去用的話記得依你們的隊伍重新調整。
- 小抄裡按「編輯減傷」就能改每個人放的技能，也能寫自己的筆記；改好的減傷軸和筆記可以匯出成分享碼，給隊友匯入。
- 設定和筆記只存在你自己的瀏覽器裡，不會上傳。
