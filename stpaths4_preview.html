P4 騎士 ST 一圖流

照時間順序列出 ST 這一 P 要去哪、開什麼。終審判決、一測、二測看自己的 debuff，所以列出每種情況；藍色是 ST。時間是 P4 開始後的時間。

00:00終審判決（看自己的 debuff）

  • 大光 → A 點方向盡量貼邊；大暗 → C 點正中
  • 小光、小暗（其他 6 人）→ C 點上方集合，小暗盡量靠近大暗
  • 大光或大暗死掉會連帶小光／小暗一起死＝團滅

00:07動靜 ×2

  • 禁止命令（靜）：讀條過半前按 ESC 取消選中，然後完全不動，連打字都不行
  • 行動命令（動）：一直移動或原地一直跳
  • 動靜判定後還有約 3 秒可以去 debuff 位置

00:27制導 ×2

  • 分散：ST 和 T、補師往上半場
  • 分攤：盡量 3～5 人一組，單吃會有全場 AOE

00:48一測（看自己的影子）

  • 讀條時找沒人的地方看自己的影子，影子身上的特效就是等等被點的機制
  • 大圈 → 沒雷射的分身面前、圓形中間；電 → C 點旁沒雷射的安全區左邊；分攤和沒點名 → 同區右邊

01:39第一次死刑：雙 T 分攤

  • 加重誅罰打一仇 3 下，雙 T 一起分攤
  • ST：極致護衛＋鐵壁＋聖盾陣，再給團隊雪仇
  • 三下打完雙 T 分開；誅罰讀條結束前換好 T，讓 MT 滿血吃誅罰

02:03二測（看自己的影子）

  • 大光 → A 點方向貼邊；大暗 → B 點；小光 → 大暗左上；小暗依近線／遠線／無點名分到大暗旁邊
  • 先處理 5 人分攤和超級跳，再光上暗下四四分攤，最後去月環分身腳下
  • 中間的分攤／分散開聖光幕簾

03:18第二次死刑

  • 照團隊安排誰吃；ST 的神聖領域留到第三次

03:37地火 ①（三穿一）＋株連 ①

  • 三穿一：第一火在左、第二火在右，第三火一定在中間，從中間穿到左邊
  • 株連 ① 開雪仇（目標減要在株連讀條結束前下）
  • 株連讀條快到一半就挑釁，準備吃第三次死刑

04:03第三次死刑：ST 無敵

  • 看到 boss 背後發光就按神聖領域
  • 吃完記得退避，接著雙 T 分散

04:23地火 ②＋株連 ②

  • 聖光幕簾要蓋到株連 ②
  • 地火結束站好定位後，株連讀條結束前開武裝戍衛

04:54籠子

  • 從 A、B 之間的籠子開始順時針落下，照隊伍排的順序（DPS 由低到高）踩 1～8 號
  • 籠子落下時裡面沒人＝團滅
